# XREAL — прошивальщик для macOS

Откройте `XREAL-Russian-Updater-0.7.1.app`. Выберите USB-очки и подходящий BIN либо скачайте BIN кнопками приложения. Запись начинается только после нажатия «Установить выбранную прошивку» и подтверждения. «Проверить без записи» проверяет уже установленные файлы.

Для локальной сборки нужен Python с Tcl/Tk 8.6 или новее. Системный Python из Command Line Tools с Tk 8.5 не поддерживается: он может показывать пустое окно.

```sh
brew install python-tk@3.11
PYTHON=/opt/homebrew/bin/python3.11 bash installer/build_macos.sh
```

Сборка использует отдельную среду `work/installer-macos-venv`, проверяет версии Tcl/Tk, выполняет тесты и проверяет отображение элементов окна внутри собранного приложения. Результат — `.app` и ZIP в `outputs/macos/`. Прошивки в приложение не встроены.
