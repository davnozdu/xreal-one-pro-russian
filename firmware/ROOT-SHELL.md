# Root-доступ к очкам по USB

Штатный способ войти в XREAL One Pro (One / 1S) под `root` по кабелю USB-C.
Ничего прошивать не нужно: очки отдают две CDC-ECM сети, по ним поднимается SSH.

## Учётные данные

| | |
| --- | --- |
| Пользователь | `root` |
| Пароль | `Xreal#Root26` |
| Хеш в `/etc/passwd` | `$1$Xr7kQm2p$bCxzH1op71tPwoe.qBNMI0` |

Пароль стандартный (заводской) — меняйте его, если очками пользуется кто-то ещё,
и после смены обновите этот документ.

## Сети

Очки поднимают два CDC-ECM интерфейса, адреса выдаются link-local, macOS их
подхватывает сама, ручная настройка не нужна:

| Mac | Очки |
| --- | --- |
| `en10` `169.254.1.10/24` | `169.254.1.1` (`usb1`) |
| `en11` `169.254.2.10/24` | `169.254.2.1` (`usb0`) |

Основной адрес для работы — `169.254.1.1`. Номера интерфейсов (`en10`/`en11`) на
другой машине будут другими, смотреть их так:

```
ifconfig | grep -B3 "169.254"
```

## Проверка до входа

```
ping -c1 169.254.1.1
nc -z 169.254.1.1 22 && echo "SSH открыт"
```

Если тишина — переподключите кабель: сеть поднимается при переинициализации USB.

## Вход по паролю

```
ssh root@169.254.1.1
```

Первое подключение спросит подтверждение ключа хоста (у очков нет постоянного
host key, он пересоздаётся).

## Вход по ключу (удобнее, пароль не нужен)

Один раз скопируйте свой ключ на очки (по паролю), дальше вход без пароля:

```
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@169.254.1.1
```

Очки понимают старый `ssh-rsa`, поэтому в конфиге клиента полезно указать
алгоритмы явно — иначе новые OpenSSH откажутся:

```
ssh -i ~/.ssh/xreal_onepro \
    -o HostKeyAlgorithms=+ssh-rsa \
    -o PubkeyAcceptedAlgorithms=+ssh-rsa \
    root@169.254.1.1
```

Готовый алиас в `~/.ssh/config`:

```
Host xreal
    HostName 169.254.1.1
    User root
    IdentityFile ~/.ssh/xreal_onepro
    HostKeyAlgorithms +ssh-rsa
    PubkeyAcceptedAlgorithms +ssh-rsa
    StrictHostKeyChecking no
    UserKnownHostsFile /dev/null
```

Дальше достаточно `ssh xreal`.

## Передача файлов

```
scp -i ~/.ssh/xreal_onepro файл root@169.254.1.1:/usrdata/
scp -i ~/.ssh/xreal_onepro root@169.254.1.1:/usrdata/out.bin ./
```

## Что на устройстве

| | |
| --- | --- |
| SoC | Artosyn AR9481, 4 ядра Cortex-A ~1.272 ГГц |
| Ядро | Linux 4.9.38 |
| libc | glibc 2.25 |
| Шелл | busybox `sh` (нет `timeout`, `ss`, `top -n` без `-b`) |
| Корень | `/` только для чтения в части разделов; рабочий каталог — `/usrdata` |

## Предупреждения

- Это root на устройстве без ограничений: неверная команда может окирпичить очки
  (особенно `voctl disable`, работа с `/dev/vdec0` и разделом boot).
- Процессы, залипшие на `/dev/vdec0` в состоянии `D`, не убиваются — только перезагрузка.
- Не публикуйте свои приватные ключи и не переиспользуйте этот пароль на других
  устройствах.
